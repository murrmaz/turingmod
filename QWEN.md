# QWEN.md

Guidance for AI agents working in this repository lives in [`CLAUDE.md`](CLAUDE.md). Read it in
full before making changes: it is the one maintained reference for the commands, file locations,
architecture and conventions, and applies to every agent, not just Claude Code. Two subsystems have
their own guide beside their code, which you should also read before changing them:
`packages/backend/src/integrations/CLAUDE.md` and `packages/backend/src/platforms/CLAUDE.md`.

This file is deliberately only a pointer, so there is a single guide to keep current. Add new
guidance to `CLAUDE.md`, not here.
